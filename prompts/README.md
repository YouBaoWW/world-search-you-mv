## 使用说明

- 有角色的出图请求应附上对应官方参考图，保持实际前檐帽型、发型和服装一致；旧文中的宽檐帽描述应以参考图和 v4 记录纠正。
- 主色为邦妮粉紫 `#FF4FA8`、芬妮金 `#FFC24A`、搜索系统青 `#4FC3FF`。
- 人物立绘使用透明背景，不在立绘中加入文字、面板或特效；色带、点阵、扫描线等由引擎生成。成品封面中的标题文字按 v4 封面提示词处理。
- v4 已加入双语歌词与全片动态模糊；真实逐词强制对齐、候选插画、显示器外壳插画及竖屏版仍不是当前已实现内容。
- 原曲音频 `public/song.mp3` 不随 Git 提交，运行工程前需自行准备。仓库中的双语歌词数据保留当前时间轴。
