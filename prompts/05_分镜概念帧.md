# 05 · 分镜概念帧（GPT Image）

> 用途：给 22 个镜头各出一张概念图，用来和团队对齐画面、做宣传物料，或者在重做某个镜头前先定方向。**不会被引擎直接使用**。
> 规格：`1536x1024`（16:9 裁切）。有角色的镜头要附官方立绘做参考图。

## 统一前缀

前四章（CRT / 液晶，字符画风格）：
```
一帧音乐MV的分镜概念图，画面完全由等宽字符组成（ASCII 艺术），模仿【显示器】的显示质感，带屏幕外壳；终端程序界面风格，信息密集；不要真实的文字内容，用无意义的字符代替。
```
English: *A storyboard concept frame for a music video, rendered entirely in monospace characters (ASCII art), imitating a [DISPLAY] with its bezel; dense terminal-program interface; use meaningless glyphs instead of real words.*

后三章（IPS / OLED，现代动态设计）：
```
一帧音乐MV的分镜概念图，现代动态图形风格：深蓝黑或纯黑背景，细线界面、终端窗口、巨大的粗黑体字形（用色块代替真实文字），角色是黑白加单一主色的三色海报风格；画面有层次和运动感。
```
English: *A storyboard concept frame, modern motion-graphics style: deep navy or true-black ground, hairline UI, terminal windows, huge bold letterforms (blocks instead of real words), characters in a three-colour poster style (black, white and one accent); layered, with a sense of motion.*
