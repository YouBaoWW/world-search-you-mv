# 02 · 候选形态插画（GPT Image，可选升级）

> 用途：现代层（2:18 以后）的**候选卡**和**结果墙**。现在用的是字符画，生成插画后会更精致（接入方式见 HANDOFF P2-2）。
> 规格：`1024x1024`、透明背景、PNG，存为 `public/forms/<form>.png`。

## 设计思路

歌词一遍遍假设"如果你变成了 X"。片中邦妮把每一个 X 都当成芬妮可能变成的样子去比对。所以每件物品上都**藏着芬妮的一个特征**（白色帽子 + 棕褐帽带、红色领结、金发、蓝眼睛），让观众一眼看出"这可能是她"。这也对应歌里"在万物里都看见你"。

## 统一风格段

### 中文
```
单个物体的扁平插画，居中，占画面约75%。三色海报风格：只用纯黑、纯白和青色 #4FC3FF，不要其他颜色、不要渐变；
粗而干净的轮廓线，大块平涂，硬边阴影；造型简单、一眼能认出；
物体身上带一个小小的"芬妮特征"：【特征】；透明背景，没有文字、水印、边框或地面阴影。
```

### English
```
Flat illustration of a single object, centred, filling ~75% of the frame. Three-colour poster style: only pure black, pure white and cyan #4FC3FF; no other colours, no gradients.
Bold clean outlines, large flat fills, hard-edged shadows; simple, instantly recognisable shape.
The object carries one small "Fanny" detail: [DETAIL]. Transparent background; no text, no watermark, no frame, no ground shadow.
```

## 验收

- [ ] 只有黑、白、青三种颜色
- [ ] 缩小到 64px 宽还认得出是什么东西
- [ ] "芬妮特征"小而明确，不抢物体本身
- [ ] 透明背景
