## 2. 风格：三色海报立绘（参考 NancyLu 视频）

参考视频里的角色立绘是**黑 + 白 + 一个主色**的三色海报风格：大面积纯白高光，深黑阴影，再用一个主色块做点缀。本片沿用这个做法，每个角色只用自己的主色：

- 邦妮：黑 / 白 / 粉紫 `#FF4FA8`
- 芬妮：黑 / 白 / 金 `#FFC24A`

画面上，立绘会叠在一条同色的斜切色带上（参考视频里的蓝色平行四边形），背景是深蓝黑或纯黑。

### 全局风格段 · 中文

```
以附带的参考图为准，保持角色的脸型、发型、帽子、服装和配饰一致。
日系二次元角色立绘，三色海报风格：只用纯黑、纯白和一个主色【主色】，不要其他颜色、不要渐变；
硬边赛璐璐阴影，大面积纯白高光，阴影是平涂的纯黑块，线条利落；头发分成大块的黑白，带少量主色反光；
半身或三分之四身构图，人物占画面高度约90%，底部自然裁切；
透明 PNG 背景（本工程不自动抠绿），没有文字、水印、边框、地面阴影或其他人物。
```

### 全局风格段 · English

```
Match the attached reference images: same face, hairstyle, hat, outfit and accessories.
Anime character illustration in a three-colour poster style: only pure black, pure white and one accent colour [ACCENT]; no other colours, no gradients.
Hard-edged cel shading, large pure-white highlight areas, flat solid-black shadow shapes, crisp linework; hair rendered as big black and white masses with a few accent-colour glints.
Half-body or three-quarter framing, figure fills ~90% of the frame height, cropped naturally at the bottom.
Transparent PNG alpha background; no text, no watermark, no frame, no ground shadow, no other characters.
```

把【主色】/ [ACCENT] 换成：邦妮 `hot pink-violet #FF4FA8`，芬妮 `golden yellow #FFC24A`。

### 生成参数

`size: 1024x1536`、`background: transparent`、`quality: high`、`output_format: png`（道具用 `1024x1024`）。

## 4. 分镜特效（引擎负责，不要画进图里）

| 特效 | 镜头 | 说明 |
|---|---|---|
| 像素头像 · 半格渲染 | S03–S09 | 一个字符格上下各放一个像素（`▀` + 背景色），像素保持方形；描边黑色提亮成暗紫，防止在黑屏上消失 |
| 像素头像 · 数据化 | S03、S04、S11 | 像素先显示成彩色 `0/1` 字符，再"落定"成色块（参考工程的数据填充） |
| 像素头像 · 损坏 | S05、S06、S09 | 随机格子变成 `#%?@&$01` 乱码，配合扫描线 |
| 显示器染色 | 全片 | 琥珀 CRT 只剩琥珀亮度；EGA 量化到 16 色；液晶黑位发灰；OLED 纯黑 |
| 立绘板入场 | S13–S20 | 同色斜切色带 + 立绘从侧面滑入 |
| 点阵虚影 | S14、S18 | 立绘按亮度转成 `. : + #` 金色字符，密度和闪烁可调；S18 里随匹配度升高逐渐变清楚 |
| 画面撕裂 | 故障值高的段落 | 横向切片错位，偶尔反色 |
| 换代转场 | 24/60/100/140/190 秒 | 消磁、CRT 关机塌线、背光预热、OLED 像素逐个点亮 |
